# KRUMBLE ROASTERS · Origin Map

크럼블 로스터스 매장에서 쓰는 커피 산지·농장 지도입니다. 손님이 커피 이름을 검색하거나
지도의 핀을 누르면, 그 커피가 자란 산지와 농장이 세계 지도 위에 표시됩니다.

**바로 보기: <https://jejukims.github.io/krumble-origin-map/>**

## 무엇이 들어 있나

| 구분 | 내용 |
|---|---|
| **크럼블 라인업** | 매장에서 쓰는 생두 3종 — 산지·농장·품종·가공·컵노트 |
| **카탈로그** | 국내에 유통되는 생두 **2,842종** · 산지·농장 **165곳** · **33개국** |
| **출처** | [생두모아](https://saengdoo-moa.com) · [FIND MY GREEN COFFEE](https://findmygreencoffee.com) 공개 목록 (2026-11-21 수집) |

같은 생두가 두 사이트에 함께 올라 있으면 이름을 맞춰 한 건으로 합쳤습니다.
수집한 목록은 3,856건이고, 중복을 걷어낸 것이 2,842종입니다.

## 화면

- **지도** — 산지·농장·국가 단위 핀. 핀 숫자는 그곳에서 온 생두 종수
- **검색** — 원두 이름, 산지, 농장, 품종, 가공 방식, 컵노트로 검색
- **산지 카드** — 좌표, 그곳에서 온 생두 목록, 주요 가공·품종·컵노트
- **생두 카드** — 국가·지역·농장·품종·가공·컵노트와 출처
- **딥링크** — `?coffee=el-diamante`, `?bean=b0001`, `?place=R%7C에티오피아%7C예가체프`, `?q=구지`
- 모바일 화면 대응

## 좌표에 대하여

산지 좌표는 OpenStreetMap을 [Photon](https://photon.komoot.io/)으로 조회해 넣었고,
주요 산지는 관리 중심지 좌표로 보정했습니다. 카드의 배지로 근거 수준을 구분합니다.

| 배지 | 뜻 |
|---|---|
| **농장 좌표** | 농장·에스테이트 위치를 확인 |
| **마을 단위** | 산지 마을·읍 단위 좌표 |
| **산지 단위** | 주·도·지역 단위 좌표 |
| **국가 단위** | 생두 이름에 산지가 없어 국가 대표 좌표로 표시 |

이름에 산지가 없는 생두(예: 등급만 표기된 `케냐 AA`)는 국가 단위로 표시합니다.
좌표를 억지로 추정하지 않습니다.

## 데이터 파일

- `beans.json` — 카탈로그 본문(생두 2,842종 + 장소 165곳). 페이지가 직접 불러옵니다.
- 가격·매입 정보는 넣지 않습니다. 손님용 화면이기 때문입니다.
- 컵노트·품종·가공 표기는 판매처마다 달라 다를 수 있습니다.

## 직접 실행하기

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

`index.html`과 `beans.json`을 같은 폴더에 두면 됩니다.
